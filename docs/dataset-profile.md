# EconoCausal Synthetic Dataset Profile & Validation Audit

## 1. Provenance & Dataset Source
- **Origin**: Synthetic promotional campaign benchmark generated via Python and NumPy simulation (`src/data/generate_econocausal_dataset.py`).
- **Generation Source**: Generated by Claude simulation, not real customer records.
- **Validation Script**: `src/data/validate_econocausal_dataset.py`.
- **Validation Status**: Fully executed locally — **68 / 68 checks passed (100%)**.

## 2. Actual Verified Shape & Schema
- **Main Dataset (`data/raw/econocausal_synthetic_dataset.csv`)**:
  - Dimensions: 20,000 rows × 45 columns
  - Missing Values: 0 nulls across the entire matrix
  - Customer IDs: Unique integers (range 100,001 to 120,000, 0 duplicates)
- **Evaluation Ground Truth (`data/raw/ground_truth_evaluation.csv`)**:
  - Dimensions: 20,000 rows × 69 columns
  - Strictly isolated in `data/raw/` and excluded from model features via `.gitignore` to prevent post-treatment leakage.

## 3. Treatment & Outcome Definitions
- **Treatment Arms ($T \in \{0, 1, 2, 3\}$)**:
  - Arm 0: 0% discount (Control) — 7,584 observations (37.92%)
  - Arm 1: 5% discount — 5,395 observations (26.98%)
  - Arm 2: 10% discount — 4,266 observations (21.33%)
  - Arm 3: 20% discount — 2,755 observations (13.78%)
- **Treatment Representation Resolution**:
  - Selected multi-arm percentage discounts (0%, 5%, 10%, 20%) over the original illustrative $10 vs $20 flat scheme. Percentage discounts properly scale concessions across heterogeneous basket sizes ($100 to $15,000) rather than distorting small vs large baskets.
- **Observed Outcomes ($Y$)**:
  - `purchased`: Binary indicator ($Y \in \{0, 1\}$); overall purchase rate = 32.71%
  - Raw purchase rate by arm: Arm 0 = 31.63%, Arm 1 = 30.95%, Arm 2 = 32.35%, Arm 3 = 39.71% (demonstrates targeted confounding where Arm 1 purchase rate < Arm 0)
  - `basket_value_before_discount`: Observed catalog basket value (Mean: $1,296.82)
  - `discount_amount`: Concession awarded ($0 for non-purchasers, $\text{basket} \times \text{rate}$ for buyers; Mean: $27.76)
  - `revenue`: Realized gross inflow ($\text{basket} - \text{discount}$; Mean: $389.91)
  - `cost_of_goods`: Wholesale cost (Mean: $248.59)
  - `net_profit`: Realized profit ($\text{revenue} - \text{cost\_of\_goods} - \text{marketing\_cost}$; Mean: $132.60)

## 4. Confounders & Adjustment Variables
- **Observed Backdoor Confounders ($W$)**: Customer engagement, recency, cart abandonment rate, loyalty status, past discount response rate, historical spend, and competitor price index.
- **Confounding Magnitude**:
  - Raw Standardized Mean Difference (SMD) reaches up to 0.525.
  - Naive gap for 5% vs 0% discount is -0.68%, whereas the true Average Treatment Effect (ATE) is +3.82%.
  - Covariate balance post-IPW using true propensities drops to max SMD = 0.0544 (< 0.1 threshold).

## 5. Financial Definitions & Known Assumptions
- **Zero-Out Rule**: For non-purchasers (`purchased == 0`), `revenue`, `discount_amount`, and `cost_of_goods` are strictly 0.0.
- **Net Profit Identity**: $\text{net\_profit} = \text{revenue} - \text{cost\_of\_goods} - \text{marketing\_cost}$. Non-buyers yield $-\text{marketing\_cost}$.
- **List-Price Conservation**: $\text{revenue} + \text{discount\_amount} = \text{basket\_value\_before\_discount}$ for all purchasers.
- **Unit Economics**: Gross margin per item is roughly 35-40% of baseline retail value before discount deductions.

## 6. Validation Performed & Results
- **Validation Suite**: 68 automated unit checks in `src/data/validate_econocausal_dataset.py`.
- **Positivity / Overlap**: Minimum propensity observed is 0.0424 (> 0.02 theoretical floor). Only 1.36% of observations fall below 0.05.
- **Leakage Prevention**: Covariates remain identical when re-drawing treatment. No outcome features leak into pre-treatment vectors.
- **Downstream Estimator Compatibility**: Doubly Robust / DML-style cross-fitted ATE within 0.0084 of ground truth; PSM balance achieved (SMD < 0.08); Qini curve positive; SciPy LP budget optimization returns feasible allocations.

## 7. Limitations & Outstanding Checks
- Data is entirely synthetic and assumes unconfoundedness holds conditional on observed pre-treatment covariates.
- Heterogeneous treatment effect estimation in Phase 1 Day 4 will need to explicitly evaluate DML double-robustness against nonlinear interactions and regularized nuisance estimators.
